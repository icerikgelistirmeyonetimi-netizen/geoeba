🛡️ Mimari Standartlar ve Kurallar
  • Strict TypeScript: Tüm veri modelleri (Curriculum, Mission, Shape) katı arayüzlerle (interface) tip güvencesindedir.
  • Zero Memory Leaks: ResizeObserver ve Web Speech API bileşen unmount olduğunda temizlenir (garbage collection).
  • 60 FPS Donanım İvmesi: SVG `` dönüşümleri ve Canvas çizimleri GPU hızlandırmalı çalışır.
  • Tam Bağımsızlık: Dış CDN bağımlılığı yoktur; okul interneti kopsa dahi tam çevrimdışı çalışır.
